BRS-TLL-040	Require all Target lesion(s) labeled in Session 1, are assigned using the same drawing tool (free form) in each assessable time point in Session 2 (Follow-up).
•	If not assigned, upon signoff apply the status of ‘Missing due to Not Readable Time Point’ with a technical adequacy response of ‘Not Readable’ in Session 2.
BRS-TLL-045	When assigning a target lesion, require a lesion drawn with the free form tool to have a value >0 in both axis (LDi and SDi). For example, a ROI drawn with LDi=5 mm and SDi=0 when right click do not provide the context menu to add or assign the ROI.
BRS-TLL-050	Lesions that fall below 5mm, either node, will be assigned a default value of 5 mm for the axis (LDi and/or the SDi) with the exception on BRS-TLL-046 when applicable.
A lesion will only be assigned a status of TSTM when the response value SA for nodal and LD for extranodal have a recorded final value of 5mm due to default added. 
This rule also applies to target lesions that split, and the fragment(s) that fall below the TSTM threshold of 5mm.
For Example: A nodal lesion that previously measured 18 mm  15 mm decreased to 4 mm  4 mm.  Assign a status TSTM and 5 mm  5 mm will be recorded for the purpose of calculating final response.  If only one (1) axis fell below the TSTM threshold, only that measurement will be recorded with the default of 5mm applied, (e.g., a nodal lesion now measuring 6mm x 4mm would have the 5mm default applied to the SDi and would have a status of TSTM. If these same measurements exist for an extranodal lesion, the default of 5mm would be applied to the SDi, however the TSTM status would not apply because the LDi is >5mm.)
BRS-TLL-055	Image Display must offer a Merge option in the lesion context screen at Follow-up to assign one or more established Target lesion label(s) to an already assigned target lesion label.
•	System applies a status of Merged-Not Present [LESION LABEL] to the established label(s).
•	Target lesions with a merged status of “Merged – Not Present [LESION LABEL]” will not count as missing when determining time point response. LD/SA will be defaulted to ‘0’ this is not a calculation.
